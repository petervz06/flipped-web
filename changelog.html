Changelog

1.0.11
May 3, 2026
Mac app
  • Sidebar device row is live: countdown of remaining session time, "Online · idle" when free, "Not signed in" when needed.
  • Schedules tab leads with a "Next 7 days" preview strip — every scheduled flip across the upcoming week visible at a glance.
  • End-of-session push notification: "Welcome back — your phone is free" fires from both local-timer expiry and server-poll detection.
  • Real stats wiring: today / week / total flipped seconds all read from the sessions table; no more "week / 7" approximation.
1.0.10
May 3, 2026
Settings → Get Help
  • "Copy Diagnostics" button puts a structured snapshot (version, device, active session, last error) on the clipboard. No password / token in the blob.
  • "Send Feedback" textarea — backend logs at WARNING (Sentry-captured) and writes a user.feedback event so the admin timeline shows full context.
Settings → Danger
  • "Export My Data" downloads a JSON of every row tied to your account (GDPR Article 20).
  • "Delete Account" cascades the delete server-side, revokes license keys, removes MDM enrollment (GDPR Article 17).
1.0.9
May 3, 2026
Profiles
  • Sync iPhone button in the Profiles header + auto-sync on app launch and tab open (5-min debounce). Picker stays fresh without you remembering to tap it.
  • Edit button on every profile. Editing a preset (Simple / Deep Work / Nomad) auto-clones to a custom — originals untouched as a factory reference.
1.0.8
May 3, 2026
Onboarding hardening
  • "DURING SETUP" yellow callout on the Rules card sets the partial-setup expectation BEFORE the destructive flow runs.
  • "Start Installation" gate before the backup/restore phase. No more surprise iPhone reboots.
  • "Pro tip" on the Done screen: put apps in one folder so flip/unflip cycles don't shuffle the home screen.
  • Active session card shows the actual blocked-apps list (tap "N apps hidden ▼").
Settings → Always Allow
  • Add bundle IDs that survive every flip — fixes web-clip PWAs (Pulse, etc.) that aren't in iOS's app list.
Build pipeline
  • otool guard refuses to ship if any bundled binary references absolute Homebrew paths — auto-prevents the dyld regression that broke the first friend test.
